# Job hunt

The morning job hunt (`morning-job-hunt` skill). **Operator mode.**

## Search criteria

- Roles: entry-level data analyst, financial analyst, BI analyst. The exact
  target is still open, so include all three and say which fits best.
- Location and remote preference: ask the user the first time, then write
  the answer here.
- Sites: Built In first (`daysSinceUpdated=1`), then others the user names.
- Posted within the last day. Check the posting's own date, not the list's.
- Entry level: skip roles that ask for several years of experience.

## Resume

- Base resume: `base_resume` in `workspace.config`. Never edit it.
- Tailored copies and `job_tracker.csv` go where `workspace.config` says.
- Ask before applying to anything.

This used to be a cloud routine that got suspended when the PC was off at
7:37am. Now it runs when the user asks for it.
