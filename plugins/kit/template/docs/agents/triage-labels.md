# Triage labels

The five default roles, written as `Status:` lines in ticket files (there are
no GitHub labels here):

| Role | String |
| --- | --- |
| needs triage | `needs-triage` |
| needs info | `needs-info` |
| ready for agent | `ready-for-agent` |
| ready for human | `ready-for-human` |
| won't fix | `wontfix` |
